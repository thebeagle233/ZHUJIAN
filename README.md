# 筑见 ZHUJIAN：面向年轻人的非遗数字传播产品

# 体验链接： https://glowing-pithivier-ae2ff3.netlify.app/

## 1. Demo 简介

**是什么：**

筑见 ZHUJIAN 是一款 Web App，通过手势交互将难以被看见和传播的**建筑非遗营造过程**，转译为年轻人**可体验、可生成、可分享**的数字内容。用户完成互动后，系统会生成专属结果，并记录营造过程形成短视频分享卡片，便于通过链接快速分享与传播。

产品未来将持续收录并转译多项建筑非遗营造技艺，目前 Demo 仅开发了以“巴青牦牛毛帐篷”为原型的首个互动主题。

## 2. 创作思路

### 灵感来源

作为建筑师，我们在学习和走访中感受到，许多传统营造技艺正随着传承人减少而逐渐消失，相关记录也十分有限。因此，我们希望把难以呈现的营造过程转化为可参与、可传播的数字体验，让更多人有机会接触这些文化。

### 想解决的问题

建筑非遗传承的是背后的营造技艺，而不是建筑结果。但建筑受到地域限制，即使亲临现场，也很难看懂其材料处理、结构组织和建造过程。

同时，许多非遗首先面临的是**如何被大众看到、激发兴趣**。现有数字化产品往往侧重系统性学习，缺少吸引原本不了解非遗的人参与的轻量入口。

### 为什么做这个方向

我们希望顺着年轻人“偶然看到—产生好奇—进一步了解”的路径，用手势交互呈现核心营造动作与结构逻辑，再通过视频和个性化结果卡片降低参与、分享门槛，让用户在创作和传播自己的作品时接触建筑非遗。

筑见希望成为非遗进入大众生活的入口：**先让人愿意体验和分享，再引向更深入的了解。**

## 3. 主要功能

### 核心功能一：用手势交互体验巴青牦牛毛帐篷营造过程

摄像头实时识别用户的双手动作，引导用户依次完成编织、张拉、平衡、落地等关键步骤，让一座巴青牛毛帐篷在动作中逐渐成形。这一设计源于牛毛帐篷“由材料、力量与身体共同建成”的特点。相比单纯观看图文，用户需要亲手控制纤维、布面与结构的变化，从而更直观地理解这项建筑非遗背后的材料特性和受力逻辑。

### 核心功能二：生成属于自己的帐篷卡片

系统根据用户操作过程中的动作幅度、稳定程度和完成状态，生成专属的帐篷名称、稳定度与结构状态，让每一次营造都得到不同结果。

个性化结果将一次短暂的互动转化为“这是我撑起的帐篷”。不同的帐篷名称、稳定度和结构状态，不仅带来参与感、完成感和个人认领感，也会激发用户分享自己的结果、查看他人的帐篷，并比较彼此差异，从而形成自然的传播动力。

### 核心功能三：把体验变成可分享的作品

体验完成后，系统将个人结果、营造过程视频、技艺来源和历史说明整合为一张可浏览、可播放、可通过链接分享的结果卡片。这一功能让非遗体验不在交互结束时停止：用户分享的不只是一个分数，而是一段亲手完成的营造过程。个人结果成为传播入口，也让更多人通过他人的作品认识巴青牛毛帐篷营造技艺。

### 核心功能四：非遗介绍

体验与传播结束后，回归到系统性知识传播。
